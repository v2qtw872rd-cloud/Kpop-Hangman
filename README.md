# Kpop-Hangman
Do you like Kpop? Do you like playing the classic game "Hangman?!" If both questions spark interest in you, then I present you "Kpop Hangman," a mix of Kpop songs and the classic game "Hangman." Though the shortness of the file may shock you, this game combines two interests into one!
This file imports "random" for the program as a whole. Next, it configures all of the songs, picks the secret word, and converts it into a usable state. After that, "conditional list comprehension" is used to neatly wrap all the logic for the list all-in-one!
The lives are defined, the text is printed, and finally a "while" loop is used to start the game in the terminal while checking all of the edge-cases such as if the guess is correct or wrong and handling game progress and lifetime.
